# プロダクト方針（ベスト筋トレ）

## 目的

**そのときの条件に合った筋トレメニュー**を提示するスマホアプリを、友人と共同開発する。

最優先する価値は **健康・長く続くこと**（見た目や競技特化より、無理のない一貫性と回復）。

## コア体験

1. ユーザーが条件を入力する（例：自宅／ジム、使える器具、使いたい時間、体の状態）。デモでは「体の状態」ステップを試験実装済み（[demo/src/lib/menu.ts](../demo/src/lib/menu.ts)）。
2. アプリが条件を満たす **メニュー案** を提示する（種目・セット・回数の目安、代替案を含めてもよい）。

## ジム・店舗まわり（実装したい方向性）

- **店舗の検索・登録**（ユーザーが利用するジム／店舗を選び、必要なら登録する）。
- **店舗情報から器具が分かる状態**にする（店舗に紐づく器具リストを参照し、メニュー生成の前提にする）。
- データの正確さは、当面 **ユーザー入力・コミュニティ整備** を前提にし、段階的に精度を上げる想定。

## 画面デモ

ローカルで動かすブラウザ向けのたたき台を [demo/](../demo/) に置いています（Vite + React）。本番のスマホ実装とは独立したプロトタイプです。
