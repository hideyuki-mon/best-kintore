# 家計簿（iPhone ホーム画面用 Web アプリ）

ADHD の人でも続けやすいことを目指した、**端末の中だけに暗号化して保存する**家計簿です。
ビルド不要・外部ライブラリなし（HTML / CSS / JavaScript のみ）。

## できること

| 分類 | 機能 |
|---|---|
| 記録 | 支出・収入の記録（金額 → カテゴリをタップで完了）／日付（今日・昨日・おととい・任意）／支払い方法／メモ |
| すぐ記録 | 「よく使う」をタップ1回で記録／カテゴリは「あとで決める」も可 |
| 自動 | 固定費（家賃・サブスク等）を毎月指定日に自動記録 |
| 見る | ホームに「今月あと使えるお金」「1日あたり」／一覧（月別・検索・絞り込み）／レポート（カテゴリ別・6か月推移・表） |
| 予算 | 月の予算・カテゴリ別予算（超過時は ⚠️ 表示） |
| 履歴 | すべての追加・変更・削除を操作履歴に保存／変更前に戻す／ゴミ箱から復元／直後の「取り消す」 |
| 管理 | カテゴリ・支払い方法の追加・編集・並び替え／暗号化バックアップと復元／CSV 書き出し |
| 表示 | ライト・ダーク・端末に合わせる |

## セキュリティ

- データは端末内（IndexedDB）にのみ保存。**通信は一切しません**（解析・広告なし）。
- パスコードから PBKDF2-SHA256（60万回）で鍵を作り、**AES-256-GCM** で暗号化。鍵はメモリ上のみで保存しません。
- 自動ロック（1〜30分）。ロック時はメモリと画面からデータを消去。
- パスコードを5回間違えると待ち時間が段階的に増加。間違いがあったことは次回解除時に通知。
- Content Security Policy で外部スクリプト・外部通信を禁止。`innerHTML` を使わず XSS を防止。
- CSV は暗号化されないため、書き出し時に警告。CSV インジェクション対策済み。
- **パスコードを忘れると復元できません。** 定期的に暗号化バックアップを保存してください。

## iPhone で使う

1. Safari で公開 URL を開く（https が必須）
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動 → パスコードを設定

## 公開方法（GitHub Pages）

1. このブランチを `main` にマージ
2. GitHub の **Settings → Pages → Source** を「GitHub Actions」にする
3. **Actions →「Deploy kakeibo to Pages」→ Run workflow** を実行
4. 表示された URL（`https://<ユーザー名>.github.io/best-kintore/`）を iPhone の Safari で開く

> リポジトリが公開(public)の場合、アプリのコードは誰でも見られますが、**家計データは各自の端末内にしかない**ので漏れません。

## ローカルで試す

```bash
cd kakeibo
python3 -m http.server 8765
# http://localhost:8765/ を開く
```
